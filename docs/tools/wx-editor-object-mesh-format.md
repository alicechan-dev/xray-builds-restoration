# Build-1935 Object Mesh Format

The wxSDKEditor mesh audit is grounded in the preserved build-1935 reader and
writer in `Editors/ECore/Editor/EditMeshIO.cpp` and the structures in
`Editors/ECore/Editor/EditMesh.h`. Object chunk `0x0910` contains numbered mesh
child chunks. Each child uses mesh version `0x0011` and the following chunks:

| ID | Preserved name | Metadata decoded in this pass |
|---|---|---|
| `0x1000` | `EMESH_CHUNK_VERSION` | 16-bit version |
| `0x1001` | `EMESH_CHUNK_MESHNAME` | zero-terminated name |
| `0x1002` | `EMESH_CHUNK_FLAGS` | recognized, not interpreted |
| `0x1003` | `EMESH_CHUNK_NOT_USED_0` | recognized retired slot |
| `0x1004` | `EMESH_CHUNK_BBOX` | six finite ordered floats |
| `0x1005` | `EMESH_CHUNK_VERTS` | vertex count and bounded record layout |
| `0x1006` | `EMESH_CHUNK_FACES` | triangle count; `st_Face` is 24 bytes |
| `0x1007` | `EMESH_CHUNK_VMAPS_0` | legacy vertex-map layout |
| `0x1008` | `EMESH_CHUNK_VMREFS` | bounded mapping-reference layout |
| `0x1009` | `EMESH_CHUNK_SFACE` | surface slots and face-index lists |
| `0x1010` | `EMESH_CHUNK_BOP` | recognized operation metadata |
| `0x1011` | `EMESH_CHUNK_VMAPS_1` | intermediate vertex-map layout |
| `0x1012` | `EMESH_CHUNK_VMAPS_2` | current vertex-map layout |
| `0x1013` | `EMESH_CHUNK_SG` | smoothing-group count/size validation |

Vertices are stored as a 32-bit count, 12-byte positions, and a per-vertex
8-bit adjacency count followed by 32-bit face IDs. Faces are triangles made of
three `{s32 pindex, s32 vmref}` records. Version-2 vertex maps store name,
dimension, polymap flag, type, record count, float values, vertex IDs, and
optional polygon IDs. Type 0 is inventoried as UV data and type 1 as weight
data. Normals are generated by historical editor code and are not serialized.

The decoder streams and seeks through these records to validate layout and
counts. It retains only metadata, bounds, counts, limited diagnostics, and
limited unknown-chunk IDs. It does not retain positions, indices, UVs, weights,
textures, shaders, thumbnails, or GPU resources.

The lawful production audit found 2,418 version-17 meshes, 7,686,510 vertices,
12,447,670 triangles, 2,331 meshes with smoothing groups, 39 version-1 vmap
meshes, 2,379 version-2 vmap meshes, 4,796 UV maps, and 4 weight maps. The 103
observed `0x1003` chunks are the source-named retired slot, not unknown format.
No genuinely unknown mesh chunk IDs or malformed meshes were observed.
