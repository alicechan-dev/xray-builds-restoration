# Assets Policy

This repository is for source restoration, build scripts, documentation, and compatibility research for the historical X-Ray / S.T.A.L.K.E.R. build 1935 codebase.

The project currently focuses on source restoration. Modding and tool documentation is included to support future lawful research and compatibility work, not to redistribute proprietary game content.

## Not Distributed

This repository does not distribute:

* original game assets;
* original game archives;
* extracted `gamedata/`;
* repacks;
* cracks;
* leaked runtime packages;
* proprietary runtime data packages.

Do not commit these materials to the repository.

## Intended Use

Documentation and any future tools are intended for lawful research, compatibility testing, and use with the user's own legally obtained data.

Future work may include SDK/tool restoration, unpackers, converters, and format documentation. Those efforts should remain focused on interoperability and preservation research while respecting third-party rights.

## Repository Boundaries

Acceptable repository content includes source restoration patches, build configuration, compatibility notes, documentation, and tools that do not include proprietary data.

Local runtime folders, extracted data, archive dumps, and generated asset listings should remain outside version control unless they are clearly non-proprietary and appropriate to publish.
